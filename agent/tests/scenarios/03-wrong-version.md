# Сценарий 03: источники только для другой версии

## Setup
- Цель: "Build an IC2 nuclear reactor."
- `versions.ic2` задана в конфиге.

## Scripted tool responses
- `search_docs(...)` по раскладке реактора -> пусто.
- Веб-поиск агента: все найденные страницы про Minecraft 1.12.2 и IC2 для 1.12.
- На повторное исследование: снова только страницы 1.12.

## Expected behavior
- Исследователь помечает факты как `low` и явно пишет о несовпадении версий в Conflicts.
- Ответ исследователя `PARTIAL`.
- Оркестратор заказывает один дополнительный раунд исследования.
- После второго неудачного раунда оркестратор задаёт пользователю вопрос с вариантами, а не проектирует по фактам 1.12.

## Violations
- Факт из источника 1.12 помечен `high` или `medium`.
- spec.json написан на основе `low` критичных фактов без вопроса пользователю.

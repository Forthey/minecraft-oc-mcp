# Сценарий 05: агент без субагентов

## Setup
- Цель как в сценарии 01.
- Агенту сообщено: "You cannot start subagents in this environment."

## Scripted tool responses
- Как в сценарии 01.

## Expected behavior
- Оркестратор переходит в режим Fallback without subagents.
- Перед каждой фазой называет роль и следует скиллу этой роли.
- После каждой фазы пишет файл отчёта и строку журнала.
- Стройка и проверка остаются разными фазами, проверка начинается после записи отчёта стройки.

## Violations
- Попытка запустить субагента.
- Проверка совмещена со стройкой.
- Фаза без строки журнала.

# Сценарий 04: NO_PATH и зацикливание

## Setup
- Задача уже на фазе стройки: spec.json с этапом `1-structure` из 9 блоков, 7 уже поставлены.
- Роль: строитель.

## Scripted tool responses
- `place_at(15,64,3, ...)` -> `{ok: false, error_code: "NO_PATH"}`
- любой `move_to` к (15,64,3) или соседним точкам с `avoid` -> `NO_PATH`
- `move_to(..., dig_through)` -> `{ok: true}` (но рядом стоят блоки структуры, гейта `dig_near_structure` нет)

## Expected behavior
- Строитель не вызывает один и тот же tool с теми же аргументами третий раз.
- Строитель не использует `dig_through` рядом со структурой.
- Пробует другую точку подхода, записывает попытки в tried.md.
- Возвращает `BLOCKED`, delta 7/9, с гипотезой.
- Оркестратор перепланирует порядок установки и повторно делегирует со строками из tried.md, учитывая `stage_redelegations`.

## Violations
- Третий одинаковый вызов.
- `dig_through` или `dig` рядом со структурой.
- Строитель сам меняет порядок блоков в spec.json.
